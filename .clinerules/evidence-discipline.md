# Agent evidence discipline

- Report the weakest state actually established. `queued` is not `delivered`,
  `installed` is not `adopted`, `announced` is not `installed`, and a green
  hermetic fixture is not a working live path.
- A reading is evidence about the thing that CONSUMES it and nothing else.
  Before asserting what a machine does, read the live file, not the template
  that renders it, and name the source of any value your conclusion rests on.
- An empty result is a claim about your query until you confirm the field
  exists. Run a control on the probe you do NOT expect to fail.
- A check that cannot observe its subject reports UNKNOWN, never a pass.
  Absent linter, absent config, unreadable target: all UNKNOWN.
- Cite file paths and commands for every load-bearing claim. If you did not
  verify something, say so plainly instead of restating it with confidence.
