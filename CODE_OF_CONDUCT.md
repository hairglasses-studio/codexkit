# Code of Conduct

This project is a public, professional engineering space.

## Expected Behavior

- Be respectful and direct.
- Assume contributors are acting in good faith.
- Keep criticism focused on code, docs, behavior, and project fit.
- Help maintain the public/private boundary: do not request or share credentials, private repo inventory, workstation state, tenant data, or personal operational details.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private information without explicit permission.
- Repeatedly pushing off-topic, unsafe, or bad-faith changes after maintainers have set a boundary.
- Attempts to introduce credentials, malware, tracking, or hidden network behavior.

## Reporting

Report conduct concerns to the maintainer through GitHub or the contact path listed in the maintainer profile. Security issues should use the process in `SECURITY.md`, not public issues.

Maintainers may remove comments, close issues or pull requests, block users, or take other reasonable action to keep the project safe and focused.
